📸 Webcam Photobooth
A fun webcam application with real-time photo effects and snapshot capabilities.

✨ Features
Webcam Access: Live video feed from your camera

Real-time Effects: RGB split and other pixel manipulations

Take Photos: Capture snapshots with camera sound

Photo Strip: Gallery of captured photos with fun rotations

Custom Effects: Red effect, RGB split, and greenscreen options

🚀 How to Use
Allow camera access when prompted

See yourself with cool RGB split effect

Click "Take Photo" to capture snapshots

View your photos in the rotating strip below

Tech: Webcam API, HTML5 Canvas, Pixel Manipulation, JavaScript
